# Jeff Golden Ad — Golden's Diner

A single-page web ad for Chef Jeff Golden and Golden's diner in Utica, NY.

Built from the Google Drive folder "Golden's — Photos, Articles & Reviews" (compiled August 2026) plus public articles and reviews.

## View it

Open `index.html` in a browser, or visit the GitHub Pages URL once enabled:

https://jagtech00-source.github.io/jeff-golden-ad/

## What's in it

- Hero with kitchen portrait
- Story section (Clinton House → Turning Stone → Golden's)
- Embedded video reel (Takes 'N Plates)
- Photo gallery
- Review stats and quotes
- Call-to-action with phone number
